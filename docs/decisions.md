# Решения

2026-10-07, CR-001: пользователь заменил Stars на внешний сервис ЮMoney и попросил сценарий бюджета $10. Stars удалены из области реализации; выбран ЮKassa как обратимое допущение для коммерческого эквайринга. Заказ номинирован в RUB/копейках, webhook перепроверяется API, финансовая модель использует комиссию эквайринга. Миграции нет: проект новый, платёжного кода ещё не было. Тесты валюты адаптированы до реализации. Ограничение Telegram цифровых услуг сохраняется даже при внешнем сайте; модуль checkout остаётся отдельным sandbox без кнопок покупки в боте. Не выдаём этот подход за разрешённую обходную схему.

Jev фактически вызван: jev-1.13.0, input577/output59; рекомендовал gpt-6.1-sol для независимого ревью. confidence0.48 — концентрация выбора, не вероятность корректности кода. Независимое ревью фактически выполнено агентом gpt-6.1-sol; три найденных ошибки исправлены и повторно проверены.

2026-10-07, CR-002: пользователь выбрал сначала локальный тест, затем VPS. Сервер не арендовать до настоящего PoC. Vibe использован только как источник архитектуры платежей; mobile/IAP отключён по умолчанию и предназначен для подписок App Store/Google Play.

2026-10-07, CR-003: владелец добавил ключи и поручил запустить photo_editortest_bot на ПК без денег OpenAI. Выбран явный DEMO до пополнения, ключи сохранены. Реальная генерация не выполнялась. Добавлены start/stop/status, lock, раздельные данные, безопасные quota/auth ошибки и существующий proxy-маршрут Telegram.

2026-10-07, CR-004: после исследования официальных возможностей Telegram владелец поручил реализовать нижнюю клавиатуру и Mini App. Принят локальный API в существующем процессе bot/worker, отдельный browser DEMO и подписанный Telegram-вход; один ledger, без второго генератора/worker. Подтверждение цены, помощь без порчи черновика и повторная выдача собственного файла входят в приёмку.

2026-10-07, CR-005: владелец разрешил немедленную публикацию исходников на GitHub и HTTPS-интерфейса на GitHub Pages. Pages размещает статические файлы, API остаётся локальным до VPS. Публичный интерфейс без API показывает предпросмотр, не отправляет фотографии, не имитирует попытки/результаты и не обращается к localhost. Секреты, личные медиа, runtime/routing-данные исключены; автор коммитов использует GitHub noreply.

2026-10-07, CR-006: все изображения оформления делает владелец. Обязателен конкретный brief: назначение, размеры, количество, содержание, формат, место. ТЗ сохранено в design-assets-brief.md и дополняется при следующих потребностях. До получения материалов — подписанные места для примеров и обычные Unicode-иконки; самостоятельно artwork не создаётся.

2026-10-07, CR-007: владелец подтвердил пополнение OpenAI на$10 и поручил начать работу. Активирован локальный OpenAI-пилот с прежней Flare snapshot/medium/1024² и3административно выданными попытками единственному ранее согласившемуся Telegram-тестировщику. В новую live БД перенесена только его принятая политика согласия; демо-фото/балансы не переносятся. Ключи/настройки модели сохранены, анонимное DEMO и биллинг отключены. Генерация происходит только по явному подтверждению пользователя; ни старые демо-заявки, ни искусственные fixtures не отправляются OpenAI автоматически. Сумма пополнения — сообщение владельца; GET model не проверяет prepaid balance. Artwork по-прежнему предоставляет владелец.
