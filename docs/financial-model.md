# Финансовая модель v0.1 — рубли и бюджет $10

Расчёт 2026-10-07. Фактических расходов на Image 2.5 пока нет. Курс 90 ₽/$ — плановое допущение, не текущая котировка: запрос XML ЦБ в этом окружении не удался. Сценарии также пересчитываются для 80 и110 ₽/$. Цена пополнения API и валютные комиссии оператора могут отличаться.

## Проверенные ставки

[OpenAI API pricing](https://developers.openai.com/api/docs/pricing): Flare и Sunburst Standard — $5/1M текстовых входных токенов, $8/1M токенов входных изображений, $30/1M выходных image-токенов. Direct Images API не применяет cached-input скидку; Responses добавляет стоимость основной текстовой модели. Batch дешевле, но не выбран для интерактивного бота.

Формула: `C_USD = (5 × T_text + 8 × T_image + 30 × T_output) / 1_000_000`. Пример, **вымышленные** usage200/2000/1500: $0.062 =5.58 ₽ при90. Одинаковые ставки Flare/Sunburst не означают одинаковые токены на результат. Не переносим таблицу токенов Image1/1.5 на2.5.

Стоимость «загрузки» в OpenAI — обработка входного изображения в токенах, она уже в формуле. Telegram не выставляет отдельную API-плату за обычную загрузку файлов. Наш трафик/диск/CPU входят в бюджет сервера либо переменные затраты. Для масштаба: два входа по1 MiB и результат1 MiB дают3 MiB/задачу; при1000 задач/день и24hTTL это около3 GiB медиа, без резервных копий/накладных расходов. Цены хостинга и налоговый режим ещё не выбраны.

[Тарифы ЮKassa](https://yookassa.ru/docs/support/payments/fees): справочная базовая комиссия карт3.5%; с2026 НДС22% от комиссии карт → эффективная4.27% платежа. Конкретная ставка по договору. Кошелёк ЮMoney также3.5%, но в таблице без этого НДС. Отдельный сервис чеков может изменить тариф; не суммируем несовместимые тарифные предложения.

## Пакеты и экономика

Предварительно5/149 ₽,10/249 ₽,25/549 ₽. Пользователь может сделать5/10/25 обычных правок, либо2/5/12 объединений с остатком. Все кредиты считаем использованными (100% redemption); не строим прибыль на забытом балансе. Новый вариант стоит ещё кредит.

Сценарий налоговой нагрузки6% от валовой выручки — допущение калькулятора, не определение законного режима. Договор эквайринга/режим/чеки/возвраты уточняются до запуска. Чистая выручка пакета=`цена×(1−0.0427−0.06)`.

База$0.06/вызов,90 ₽/$,retry1.15,прочее1 ₽: себестоимость7.21 ₽/результат. Для10/249: комиссия10.6323 ₽; налог-сценарий14.94 ₽; остаётся223.4277 ₽; выполнение всех10 стоит72.10 ₽; вклад до постоянных расходов и привлечения151.3277 ₽ (60.77% от валовой выручки). При CAC100 ₽ вклад первого заказа51.3277 ₽. Постоянные5000 ₽/мес (допущение) покрываются34 такими заказами безCAC либо98 приCAC100 ₽. Зарплата/возвраты/касса/реклама сверхCAC не включены: это **не чистая прибыль бизнеса**.

Стресс$0.15/вызов: пакет10 даёт58.1777 ₽ доCAC, приCAC100 уже убыточен. Пакет25/549 в стрессе даёт79.4927 ₽ доCAC. Безлимит и щедрые бесплатные бонусы исключены. Для цели маржи60% при базе минимальная цена обычной правки `7.21/(1−.0427−.06−.60)=24.25 ₽`; пакет25/549≈21.96 ₽ имеет меньшую маржу.

Интерактивный расчёт: `reports/finance.html`; воспроизводимые JSON-сценарии: `python -m image_studio finance`. ИзменяйтеFX,API,CAC,отказы; сравнивайте все пакеты. После live-PoC подставить медиану иp95usage отдельно по функции/модели/quality.

## ЮMoney и ЮKassa

Выбран один checkout ЮKassa: карты и кошелёк ЮMoney доступны через одну интеграцию. [API кошелька](https://yoomoney.ru/docs/payment-buttons/using-api/notifications) проще для переводов: amount — зачисленная сумма, withdraw_amount — сумма плательщика; уведомления имеют подпись и label. Это иной продукт с другими договорами/ограничениями, не взаимозаменяемый коммерческий эквайринг. Не создаём параллельный платёжный контур без подтверждённой потребности. Sandbox интеграция ЮKassa реализуется без сторонних платёжных ссылок в Telegram. [Telegram FAQ](https://core.telegram.org/bots/payments-stars) прямо требуетStars для цифровых услуг внутри Telegram даже при наличии внешнего сайта. Выбор пользователя внешних рублей сохранён; допустимая коммерческая архитектура ещё не решена.
