# «Образ»: бюджет бета-тестирования

24.10.2026. CR-BETA-ECON-001. По уточнению владельца текущая задача — учитывать доходы и расходы бета-теста без фиксированного плана прибыли.

Владелец сообщил, что уже выдал **трём основным тестерам по50 генераций**, всего **150**, за обратную связь. Здесь стоимость полного использования этой выдачи. Дополнительных начислений не сделано; персональные данные тестеров не нужны для расчёта.

## Стоимость выдачи

Режим: текущий Sunburst Medium. Плановая цена пополнения100 ₽/$ — допущение, не курс ЦБ. Наблюдаемое значение2,55635 ₽ получено пересчётом четырёх обычных обработок с полным Image usage; малая выборка не покрывает все функции и возможные дополнительные вызовы. Источник и ограничения: [исследование геймификации](gamification-design-2026-10-24.md#2-что-проверено-что-принято-за-допущение).

| Объём | По малой выборке Image API,2,55635 ₽/результат | Плановый бюджет4 ₽/результат | Стресс-сценарий6 ₽/результат |
|---|---:|---:|---:|
| Один тестер,50 генераций | 127,82 ₽ | **200 ₽** | 300 ₽ |
| Три тестера,150 генераций | 383,45 ₽ | **600 ₽** | 900 ₽ |
| Все150 плюс один месяц общего VPS | 683,45 ₽ | **900 ₽** | 1200 ₽ |

Аренда300 ₽ начисляется на весь сервер один раз в месяц, а не по300 ₽ каждому тестеру. Если тестирование занимает больше месяца, аренда добавляется за каждый месяц. Иные пользователи, ручные подарки и отдельный видеотест администратора — дополнительные расходы, не включённые в эти150.

Это **потенциальный бюджет полного расхода**, а не доказательство, что150 обработок уже сделаны. Если часть уже использована, будущий резерв следует считать по оставшимся попыткам. По четырём наблюдениям нельзя гарантировать, что реальный полный API-расход150 результатов уложится в383,45 ₽ или600 ₽.

## Доходы и расходы учитывать отдельно

| Статья | Как учитывать |
|---|---|
| Выручка от этих тестовых выдач | **0 ₽**: выдача за обратную связь |
| Оплаты других пользователей | По подтверждённым платежам и реальному зачислению; величина здесь не проверялась |
| Генерации тестеров | Фактический usage доставленных результатов плюс оплаченные ошибки/дополнительный анализ |
| Выданные неиспользованные попытки | Резерв будущих API-расходов; не состоявшийся расход и не выручка |
| VPS | 300 ₽/месяц по ранее указанной владельцем сумме |
| Пополнение OpenAI | Движение денег на предоплаченный баланс; не суммировать повторно с потреблением API как два одинаковых расхода |
| Комиссии и прочее | Только фактические удержания/расходы; 30% из сценария продаж к бесплатной выдаче не применять |

Действующие бесплатные программы не отключаются. Если эти трое дополнительно используют регулярные подарки по одному каждые пять дней, это до18 результатов за30 дней, или **ещё72 ₽** при4 ₽/результат. Они не входят в150 ручных попыток. Стартовые/канальные и новые ручные подарки также считать отдельно, если они действительно выдаются и используются. Новая геймификация пока не запущена.

Рекомендуемый резерв именно на выданные150 — **600 ₽ на API**, плюс300 ₽ за один месяц сервера; полезно иметь возможность добавить запас, если полный расход окажется выше4 ₽. Качество тестерам не снижать автоматически ради экономии.

Остаток денег в API-кабинете — отдельный меняющийся показатель, не себестоимость одного фото. Он проверяется в [OpenAI Billing overview](https://platform.openai.com/settings/organization/billing/overview); конкретный остаток счёта не записывается в публичные документы проекта.

## Предложенная игровая награда550

Отдельно от уже выданных50 попыток владелец выбрал для проекта программы заданий итог550 бонусов:5 целых генераций и50 бонусов остатка. Игра ещё не подключена, реальных начислений этой награды нет. [Механика и граф](gamification-scenario-generator-2026-10-24.md).

На одного участника резерв5,5×4=**22 ₽**:20 ₽ на пять результатов и2 ₽ на оставшиеся50 бонусов. Для троих —**66 ₽** дополнительного обязательства. Общий план с этими наградами:600+66+300=**966 ₽**, включая один месяц общего сервера. При6 ₽ за результат:900+99+300=1299 ₽. По небольшой выборке только Image API вся награда550 около14,06 ₽ на человека, но полная стоимость может оказаться выше.

Остаток50 пока нельзя отдельно потратить как половину модельного вызова; это сохранённое право на часть будущего обмена. Резерв на него учитывается, даже если он не используется немедленно.
