# Proof of Concept

## Уже доступно

Offline-PoC: `python -m image_studio offline-poc`. Проверяет резерв→провайдер→файл→доставка→списание, отсутствие повторного вызова, объединение за2 кредита, отказ без баланса. Provider=mock, поэтому сходство лица/качество ИИ/сетевые Telegram/ЮKassa/OpenAI этим не проверены.

Установленные SDK: aiogram3.31.0 и официальный openai2.54.0. Сигнатура images.edit проверена в установленных типах; multipart/usage/errors проверены с настоящим SDK и httpx.MockTransport, без доступа к серверу OpenAI. ЮKassa: direct HTTPS API через httpx, без синхронного глобального singleton SDK; проще контролировать timeout, стабильный Idempotence-Key и безопасные ошибки. Официальный [Python SDK ЮKassa](https://github.com/yoomoney/yookassa-sdk-python) рассмотрен как альтернативный транспорт; не установлен и его использование не заявляется.

## Live-проверка Image 2.5

Состояние2026-10-07: пополнение$10 подтверждено владельцем; read-only models.retrieve успешно проверил обе модели по его ключу. Бот ready/openai, Flare/medium, отдельный live ledger с3пилотными попытками. Первый запрос запускает пользователь в боте. model lookup не доказывает остаток денег, доступ конкретного Images-запроса или качество правки; эти доказательства появятся после результата. Сравнение с Sunburst остаётся следующим измеряемым экспериментом.

1. Убедиться в доступности аккаунта и региона по [правилам OpenAI](https://help.openai.com/en/articles/5347006-openai-api-supported-countries-and-territories); при необходимости пройти организационную верификацию. Россия не включена в опубликованный список; не рекомендовать подмену страны/данных. Язык интерфейса может быть русским для допустимых регионов.
2. В отдельном API-проекте создать ключ, пополнить$10 и отключить автопополнение для ограниченного опыта. Лимиты/оповещения — дополнительная защита, не гарантированный мгновенный останов по$10. Сначала1 вызов; проверить доступ и usage, затем утвердить остаток матрицы по фактической цене. Не покупать подписку ChatGPT ради API.
3. Разместить ключ в локальном `.env`, тестовые фото с согласия людей — в непубликуемой папке.
4. Сравнить Flare/Sunburst на одинаковых фото/промптах/medium/1024²: причёска, очки, одежда, фон, улучшение, объединение. Минимум12 вызовов (6 функций×2 модели); дополнить разным светом/типами волос/цветом кожи/двумя лицами. При сценарии$0.06 →12 вызовов≈$0.72, но это не обещание реальной цены.
5. Команда на1 платный вызов:

```powershell
.\.venv\Scripts\python.exe -m image_studio live-poc --images 'C:\private\portrait.jpg' --preset hair --description 'Каре до подбородка; всё остальное сохранить'
```

Для объединения передать2 пути и `--preset merge`. Для другой модели добавить `--model gpt-image-2.5-sunburst-2026-09-08`. Никаких автоматических повторов. Результаты JPEG и JSON с latency/usage/request_id/себестоимостью в `data/live-poc`, не git. В CLI-PoC файлы сохраняются для оценки и не имеют автоматического TTL бота; удалить после оценки вручную. Не публиковать без разрешения.

6. Оценить каждое фото человеком: узнаваемость1–5, точность1–5, критические искажения, готовность платить. Не использовать распознавание лиц/биометрические идентификаторы как замену согласованной оценке. Принято, если оба≥4 и нет критических дефектов. Отдельно измерить median/p95 стоимости, latency и приёмки;12 примеров недостаточно для устойчивогоp95, увеличить выборку перед реальными тарифами.
7. Go/No-Go по PRD: если Flare приемлема — выбрать её; если только Sunburst проходит — пересчитать кредитную цену; если лица ненадёжны — сузить функции или остановить запуск.

## Telegram и ЮKassa

Telegram: отдельный тестовый BotFather-бот, `/start`, consent, `/demo` в mock, все6функций, /result только своему user_id, /delete и отказ с нулевым балансом. Для реального OpenAI-пилота администратор выдаёт до10кредитов через CLI после согласия пользователя. Это может расходовать API-баланс; не путать с бесплатным model-access.

ЮKassa: завести [тестовый магазин](https://yookassa.ru/developers/payment-acceptance/testing-and-going-live/testing), локальныеSHOP_ID/SECRET_KEY/admin-token≥32символа. Запустить `python -m image_studio billing` (loopback8088); HTTP health без внешних операций. Для уведомлений нужен отдельный HTTPS endpoint после согласованного деплоя. /orders с Bearer-токеном создаёт внутренний заказ; /checkout/ID создаёт sandbox-платёж; повтор использует тот жеID и payload. /reconcile/ID сверяет пропущенное событие. Не открывать /orders без авторизации, не отдавать admin-token клиенту. Браузерный return_url не начисляет кредиты. Обработка succeeded/refund через канонический API; webhooks без доверия к телу. Реальные платежи test=false отклоняются.

Перед коммерческим запуском остаются платформа оплаты Telegram, допустимые регионы, оператор/договор/чеки, безопасность публичного webhook/rate-limit, эксплуатация и backup. Внешний checkout не заявляется обходом требованияStars внутри Telegram.
