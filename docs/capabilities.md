# Возможности Image 2.5 и продуктовые сценарии

Проверено по официальной документации 2026-10-07. Это карта API и идей функций; качество каждого сценария надо оценить на фото пользователей.

| Сценарий | API-механизм | MVP |
|---|---|---|
| Причёска, цвет волос, чёлка | Правка фото с перечислением сохраняемых черт | Да |
| Очки, одежда, аксессуары | Референс и инструкция о замене области | Да |
| Фон, свет, сезон, окружение | Правка/новая композиция | Да |
| Ретушь, визуальная реставрация | Генеративное редактирование, возможно изобретение деталей | Да, без обещания восстановления истинных деталей |
| Объединение людей/предметов из фото | Несколько входных изображений | Да, ровно два |
| Стилизация, аватары, иллюстрации | Генерация/правка по тексту | Следующая версия |
| Товарные фото, постеры, текст на изображении | Референсы, композиция и текст | Следующая версия; возможны ошибки букв |
| Замена/удаление отдельных объектов | Правка с маской или текстом | Текст в MVP, интерфейс масок позже |
| Расширение кадра | Инструкция редактирования + новый размер | Позже |
| Прозрачный фон/вырезка | background=transparent, PNG/WebP | Позже |
| Последовательные уточнения | Responses API либо повторное images.edit результата | В MVP новая оплачиваемая операция с загруженным результатом |

Перечисленные действия — задачи для общей генеративной модели, не отдельные endpoints «haircut»/«glasses»/«upscale». Модель не является специализированным детерминированным апскейлером.

[Гайд промптов](https://developers.openai.com/api/docs/guides/image-prompting) объясняет, как явно задавать изменения и сохраняемые детали, пользоваться референсами и проверять результат. [API генерации](https://developers.openai.com/api/docs/guides/image-generation) поддерживает генерацию/редактирование, настройку размера и качества, прозрачность, streaming и multi-turn через Responses. Доступны low/medium/high/xhigh/max; рекомендуемые размеры 1024², 1536×1024 и 1024×1536; нестандартные размеры имеют ограничения, до 4K с экспериментальными большими разрешениями. В MVP параметры фиксируем для сравнимости расходов. Маска — подсказка модели, не гарантия точных границ. Лицо/текст/композиция могут измениться нежелательно.

[Анонс Image 2.5](https://openai.com/index/introducing-chatgpt-images-2-5/) описывает точность правок, детали и сохранение объектов. Возможности интерфейса ChatGPT (шаблоны, комментарии, sketch) требуют собственной реализации в Telegram; они не становятся функциями бота автоматически.
