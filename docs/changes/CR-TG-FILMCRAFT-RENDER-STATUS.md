# Статусы и повторная сборка Filmcraft

Дополняет [контракт Filmcraft](CR-TG-FILMCRAFT-002.md).

- Во время сборки показан статус Filmcraft с прошедшим временем. Telegram
  показывает отправку видео только во время загрузки готового файла.
- После тайм-аута сборки сохранённый план можно собрать снова в 720p или
  выбрать «Быстрее · 540p». Filmcraft собирает оба варианта без новых
  запросов OpenAI. Размер готового MP4 указан в сообщении.
- Отправка MP4 имеет отдельный лимит ожидания. Если Telegram не подтвердил
  отправку, готовый файл можно взять кнопкой «Скачать MP4». После подтверждённой
  отправки повторная выдача использует сохранённый идентификатор файла Telegram.
