# Рабочая папка Filmcraft

Дополняет [контракт Filmcraft](CR-TG-FILMCRAFT-002.md). Продакшен-бот работает
с `ProtectSystem=strict`. Вместе с `filmcraft.conf` установите
`filmcraft-spool.conf` в каталог `image-studio-bot.service.d`. Это даёт
процессу Telegram запись в `/var/lib/obraz-filmcraft`.

Процесс также работает с `RestrictSUIDSGID=yes` и `UMask=0077`.
Каталог работы получает обычный режим `0770`, а исходник и сообщения
между службами явно получают группу каталога и режим `0660`.
При открытии восстанавливаются права рабочей папки, оставшейся после старой
ошибки. Новая запись о работе создаётся после подготовки каталога.

Проверяйте код под настройками systemd боевого сервиса, включая seccomp.
Проверка только пространства монтирования не воспроизводит запрет выставлять
специальные биты доступа.

Сквозная проверка 24.11.2026 с синтетической речью прошла. Установленный
Telegram-обработчик открыл старую работу, создал новую, принял видео и
передал его монтажному процессу. Реальные `gpt-transcribe` и `gpt-6.2-sol`
выполнили по одному запросу. Filmcraft собрал и декодировал MP4 720×1280
с субтитрами. Установленный обработчик подготовил запрос отправки этого файла.
Транспорт Telegram в проверке заменялся тестовым. Удаление файлов по сроку
хранения также прошло, записи о расходе сохранились.
