## Контракт

- Вход: /filmcraft, «хочу сделать видео», «смонтируй ролик», «собери рилс» и
  похожие фразы о видео/монтаже. Распознавание обычных фраз кодом без платного
  классификатора; редактирование содержания/выбор фрагментов — существующим
  GPT-6.1Sol по пожеланию и выборочным кадрам. Не заявлять полное понимание любого текста.
- Owner-only проверяется для сообщения, каждого callback и каждой операции в
  приватном собственном чате. Админ ID должен совпадать с3975497; отдельный флаг
  выключен по умолчанию. Чужие сообщения не переключают состояние и не тратят API.
- Приём1–6видеофайлов, каждый≤19000000байт, суммарно≤90с; своя музыка≤5MB
  опционально. Потоковая запись в файлы с ограничителем, проверка реального
  содержимого/размера/типа; дубликаты сообщений/альбомов не добавляются повторно.
- Можно написать пожелание до/после файлов; «готово» завершает подбор. Бот
  объясняет Filmcraft, срок24ч, передачу кадров/речи OpenAI только после отдельного
  подтверждения анализа, отсутствие списания фотогенераций и отдельный расход API.
- Подтверждение анализа → ограниченная подготовка → при необходимости ASR →
  GPT-6.1Sol → строгая проверка плана → показ плана. Подтверждение сборки →
  Filmcraft CLI → проверка MP4 → документ в тот же Telegram-чат. Можно повторить
  рендер/скачивание без нового LLM. Изменение пожелания после плана требует нового
  явного подтверждения платного анализа. Никакого скрытого автоплатежа.
- Прежний AdminVideo/FFmpeg сохраняется. Отмена закрывает подбор, не удаляет
  журнал/балансы. Прерванный платный анализ остаётся review с неизвестным расходом,
  не повторяется автоматически. Ошибка Filmcraft не подменяется незаметно FFmpeg.
- Поддержать тишину/исходный звук/свою музыку, русский титр и фразовые субтитры
  при наличии расшифровки. Времена грубые по сегментам, не обещать word-level.
  Полный кадр с полями; без генерации новых видеосцен/музыки и без face tracking.
- Явные размеры/позиции титров, ограничение длины; отсутствие offscreen/заглушек
  offlineMedia. Рендер Filmcraft настоящий, FFmpeg разрешён для подготовки,
  независимой проверки и технического финального аудио/субтитрового mux, если
  формат движка потребует. Не выдавать FFmpeg-only монтаж за Filmcraft.

## Ресурсы и размещение

Отдельный непривилегированный worker без API/SSH-секретов, без сети, один процесс
сборки; cgroup лимиты памяти/CPU/числа задач. Отдельный приватный spool с фиксированными
именами файлов, JSON-команды только из allowlist. Сохранённые данные/usage отдельно
от спула. Перезапуск worker не повторяет оплачиваемый AI. Перед большим заданием
проверять свободный диск и запас RAM; при отказе объяснять занятость, не ронять бота.
Ставится проверенная pinned portable Linux v0.20.1; основная environment остаётся
неизменной, новые настройки в отдельном override. Поставить только Telegram;
соседние процессы, включая MAX/content-planner, не перезапускать.

## Приёмка

Ограниченные offline проверки: owner/чужой/группа/выключенный флаг, несколько
файлов+caption/дубликаты, неправильный файл/лимит, описание до/после загрузки,
подтверждение/отмена/устаревший callback, один анализ и повторный рендер, ошибки/
таймаут/restart, неизменный фотобаланс. Один настоящий синтетический Filmcraft
рендер установленным worker на VPS с фиксацией лимитов и независимой проверкой.
Модель и Telegram заменяются в автоматическом smoke; платные API-вызовы0.
Реальное качество собственного видео/расход AI проверяет владелец.

Поставка: backup/hash guard/idle, только нужные файлы, сохранение всех существующих
таблиц/данных/env, CI проекта, worker readiness и проверка маршрута через установленный
dispatcher. Кодовый откат сохраняет финансовые БД; исходные конфигурации не заменять
резервной копией поверх новых оплат. Только после проверки — уведомление3975497.
