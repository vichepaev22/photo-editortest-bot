# Фото по примеру — CR-REF-001

Порядок: «Образ» → локальная «Примерочная». Общее ядро — ограниченная Pydantic-схема,
анализ reference image, JSON и явно разделённые роли; адаптеры/UI отдельные.

Приёмка: свой снимок + референс; свой снимок можно повторно выбрать; меню не смешивает
референс с объединением фото. Вариант сохранить одежду запрещает перенос одежды.
Один резерв и один Image-результат; анализ только после подтверждения, без автоматических
повторов. Некорректная схема/отказ не ведут к Image. Mock не делает сетевых вызовов.
JSON/изображения под TTL и удалением; лица референса и текст магазина не являются инструкциями.
Учитывается usage обоих запросов; исходный снимок остаётся доступным для других функций.

Документация: в начале Context7 был недоступен, использованы официальные OpenAI Docs.
Позже доступ восстановился: выполнены resolve-library-id и query-docs для
`/openai/openai-python` о responses.parse, Pydantic text_format и input_image.
Context7 подтвердил AsyncOpenAI/parse/output_parsed; документация не привязана к 2.54.0,
поэтому совместимость дополнительно сверена с сигнатурой установленного SDK.
https://developers.openai.com/api/docs/guides/structured-outputs
https://developers.openai.com/api/docs/guides/images-vision
https://developers.openai.com/api/docs/guides/image-generation
https://developers.openai.com/api/docs/models/gpt-4.1-mini
SDK локально openai 2.54.0 / pydantic 2.13.5 / aiogram 3.31.0.
Новая модель анализа по умолчанию gpt-4.1-mini-2025-04-14, настраиваемая отдельно;
существующую Image-модель не заменять. responses.parse/text_format поддержаны установленным SDK.

План: schema/provider → native UI/service → Mini App → focused offline checks →
переиспользование ядра в «Примерочной» → её native/Mini App/immutable job snapshots → checks.
VPS/реальное качество фиксировать отдельно; исходные изменения result delivery сохраняются.

## Реализация и проверки

Native bot и Mini App реализованы. Анализ выполняется отдельной моделью со зрением,
JSON не нужно копировать вручную. Сохранение одежды — отдельный выбор до запуска.
Стоимость пользователю — одна попытка; затраты оператора включают анализ + Image.
Контроль ролей является правилом prompt, а не гарантией точного визуального результата.

Offline: 87 passed в пакете service/workflow/native/API; в том числе четыре новых
сценария схемы, возврата резерва, идемпотентности, переиспользования своего фото и native UI.
Ruff и Node syntax PASS. Полную локальную suite повторно не запускали.
GitHub CI обязателен для выпуска; VPS-проверка отдельно в verification.md.
Реальных платных запросов для тестирования — 0. Сходство/точность/доступность модели
анализа на данном аккаунте остаются проверкой первого пользовательского результата.

Прежняя готовая локальная доработка Telegram file_id включена как зависимость
доставки результата (CR-018); финансовые черновики не входят в этот выпуск.
