# Образ — основное техническое задание / PRD v0.5

Обновлено: 10.10.2026. Этот файл — основной источник действующих требований. При каждой правке владельца сначала обновляются соответствующие пункты этого ТЗ, затем затронутый контракт/план и реализация. Узкие документы уточняют пункты, но не заменяют их. Исторические CR в конце не отменяют текущие требования. Подтверждённую готовность фиксирует отчёт приёмки, а не наличие записи в ТЗ.

## Продукт, инфраструктура и доступ

Русскоязычная фотостудия «Образ ·» для совершеннолетних в Telegram: @obraz_photo_bot. Нативный бот работает на VPS Play2go как один systemd-процесс с постоянной SQLite WAL; Mini App опубликовано на GitHub Pages и обращается к защищённому HTTPS API того же VPS. Ключи, фотографии и статистика не публикуются в Pages/Git. Локальный запуск остаётся инструментом разработки; второй production-poller одновременно не запускается.

SDK: Python 3.12+, aiogram 3, официальный OpenAI Python SDK, Pillow и pillow-heif. Действующий Image snapshot — gpt-image-2.5-flare-2026-09-08, quality=medium, size=1024x1024, n=1; изменение модели/качества требует отдельного решения. ChatGPT-подписка, Codex и Image API имеют отдельные способы доступа и бюджеты. Разработка далее выполняется через GPT-6.1 Sol. По указанию 10.10.2026 текущая админская задача выполняется ведущим агентом без субагентов, с коротким предметным контекстом и необходимыми проверками.

## R01–R06: обработка фотографий

1. Причёска, одежда, очки, фон, улучшение качества, объединение двух фотографий и «Фото на документы». Для каждой функции свои краткие подсказки и копируемые примеры. Причёски: можно запросить 1–12 вариантов в одном изображении; это рекомендация, а не гарантия API. Один готовый коллаж — одна генерация.
2. Загрузка фото/документа в Telegram и фото с галереи/камеры iPhone в Mini App: JPEG, PNG, WebP, HEIC/HEIF. До 10 MB (10 000 000 байт) на файл, до 64 MP перед декодированием. HEIF преобразуется сервером в JPEG, ориентация исправляется, EXIF/GPS удаляются. Предпросмотр не должен блокировать успешно загруженный файл; реальная проверка gallery/camera на iPhone фиксируется отдельно.
3. Перед работой — согласие на обработку собственных фото и права/согласие каждого изображённого человека. Step1 предлагает новое фото или прежний доступный исходник, подсказку о файле и селфи у нейтральной стены. Ответ на своё фото в этом чате тоже выбирает его; само выбора фото генерацию не запускает. Для объединения нужны два исходника.
4. В текущем пробном чате описание автоматически запускает обработку после краткого Step3, без дополнительной кнопки. Mini App сохраняет явное подтверждение. Одна активная задача на пользователя; резерв до Image API, списание после сохранения результата, освобождение при ошибке. Дубликат запроса не запускает модель повторно. Interrupted running переводится в review без автоматического платного повтора.
5. Результат — файл с сохранённым качеством; повторное скачивание бесплатно и без нового Image-вызова. Фото и результаты локально хранятся 24 часа, кроме незавершённых/review до разбора. /delete удаляет локальные фото и отзывает согласия; учёт операций остаётся. Удаление не распространяется на уже отправленные сообщения Telegram и данные провайдера. После доставки удаляются только собственные сообщения шагов этой заявки; исходники и результат пользователя сохраняются. Во время обработки обновляется штатный индикатор отправки фото.
6. «Фото на документы»: одна фотография, четыре одинаковые копии 2×2, 35×45 мм, PNG 826×1062/300 DPI; выбор нейтральной одежды и вариант подготовки исходника без ИИ. В варианте ИИ один вызов Image. Приём конкретным ведомством не гарантируется. Узнаваемость человека — критерий оценки, а не гарантия модели. Водяная метка отложена до отдельного решения о названии.

## R07–R10: бесплатные генерации, покупка и поддержка

7. Каждый обычный пользователь получает одну стартовую бесплатную генерацию один раз. Любая функция, объединение и перегенерация расходуют одну попытку за готовый результат. Ошибка не расходует попытку. Существующие оплаченные/ручные остатки и история не сбрасываются. Безлимит тестирования доступен только приватно настроенному ID владельца; согласие, одна активная задача и статистика для него сохраняются.
8. После расхода первой попытки бот предлагает ещё одну за подписку одновременно на @FutureDarkSide и @nofuturenews: две ссылки и «Проверить подписку». Только подтверждённая подписка на оба канала даёт +1 один раз за всё время; отсутствие подписки понятно сообщается. Повторная проверка, выход/вступление, /start и перезапуск не продлевают бонус. Далее — приобретение пакета. Это не подарок десяти генераций: десять были отдельным ручным начислением конкретному тестировщику.
9. Пакеты на экране покупки: Express — 160 ₽ (5 генераций), Базовый — 380 ₽ (12), Premium — 790 ₽ (30). Один редактируемый экран: тариф → СБП/крипта → выбранная сумма и ссылка → отмена. СБП — success, крипта — primary, правовые кнопки нейтральные; точные оттенки задаёт Telegram. Срок 60 минут сейчас относится к DEMO-сессии. Реальный Platega-приём платежей не подключён; BILLING_ENABLED=false, sandbox не считается покупкой. Настоящее начисление только после проверенного production-события с верными владельцем, суммой, валютой и уникальным платежом. Согласовать платёжный сценарий и правила платформ до продаж. Двухмесячное ограничение купленных генераций/акционный пункт по просьбе владельца отложены.
10. Нижняя клавиатура нейтральная, только поддержка зелёная; стандартное сворачивание/вызов Telegram. «Купить / продлить доступ», баланс, результаты, помощь и функции доступны понятной навигацией, основные сценарии — за два нажатия до выбора функции. Поддержка ведёт на @nedelsky. Приветствие «Образ · ваша фотостудия» с упоминанием фото на документы, без пласта служебных команд. Формулировка возраста — «для совершеннолетних», без цифровой маркировки возраста.

Документы во всех экранах:

## R11–R17: полная админская панель

11. /admin только владельцу по приватному ADMIN_TELEGRAM_ID в личном чате; повторная проверка на каждом callback и текстовом действии. Username не авторизует. Панель работает редактированием одного сообщения; ответы поиска/ввода параметров не попадают в описание фото или поддержку.
12. Все учётные записи и фактические посетители показаны раздельно. Список по десять, фильтры «все / заходили / покупали», поиск точного ID/@username. Кликабельный аккаунт. Карточка: доступно/резерв, начисленные и стартовые генерации, тип доступа/безлимит, канал-бонус, успешные генерации, реальные покупки/сумма, первый/последний визит, согласия. Даты UTC+5.
13. +5, +10, −1, произвольное изменение и установка доступного остатка. Причина обязательна; перед применением предпросмотр «было → станет» и подтверждение/отмена. Подтверждение владельцу на пять минут, одно применение, устаревшее состояние отклоняется. Оплаченный резерв сохраняется, отрицательного остатка нет. При активном trial-резерве дождаться завершения. Безлимит владельца защищён от изменения этим инструментом.
14. Постоянный журнал изменений: исполнитель, пользователь, причина, время, остатки до/после, резерв, статус и операция. Перезапуск, /delete и истечение фото не очищают учёт.
15. Уведомления только владельцу: первое реальное посещение один раз; начало, успех, ошибка/review генерации; новый подтверждённый production-платёж после зачисления; необработанные сообщения вне выбранного сценария редактирования. Демо/тестовые платежи, повторная выдача фото и старые события не создают новые уведомления. Вопросы ограничены по длине/частоте, пользователь получает понятный ответ о передаче.
16. «События» — история, полное обращение и сведения задания. «Уведомления» — категории и общая пауза доставки. Durable outbox и квитанции; подтверждённая отправка не повторяется, известная временная ошибка допускает ограниченные повторы, неизвестный сетевой исход требует проверки. Ошибка уведомления не меняет кошелёк/генерацию/выдачу.
17. По умолчанию генерация видна как метаданные. /sharing — явное отдельное разрешение пользователя на просмотр описания и результата будущих заданий в течение 24 часов от создания; исходные фото не передаются. Отзыв закрывает доступ и удаляет описания, повторное включение не открывает историю. /delete отзывает оба согласия. Доступ к файлу повторно проверяет пользователя, задание, согласие, срок и безопасный путь.

Детали интерфейсов и ограничений: [admin-panel.md](admin-panel.md). **Публикации обновлений в двух каналах на паузе по указанию 10.10.2026**: нет активных кнопок, обработчиков или отправки; подготовку постов обсуждаем отдельно.

## Экономика, отложенные возможности и приёмка

Аренда сервера — 300 ₽/месяц со слов владельца, цель прибыли — 10 000 ₽/месяц. Себестоимость учитывать по фактическому usage Image, входам/выходу/качеству, курсу, комиссии, ошибкам и бесплатным попыткам. Пакет сам по себе не гарантирует прибыль. Расчёты — [financial-model.md](financial-model.md).

После реальной проверенной оплаты: реферальная ссылка и награда только после первой оплаты приглашённого минимального тарифа (3/5 требуют экономики); докупка пакета и предложение премиального качества при малом остатке. Эти гипотезы не внедрять в рамках админки. Публикации в каналах, watermark, тарифные эксперименты и расширенный live-PoC — отдельные этапы. Картинки оформления создаёт владелец по ТЗ, агент их самостоятельно не генерирует.

Проверки — минимальные, соответствующие изменению: авторизация, идемпотентность/баланс/резерв, восстановление/очередь, согласие/TTL и сохранение существующих сценариев. Полный обязательный CI один раз для финального релиза; дополнительные повторы только после ошибок/новых изменений. Платные Image-вызовы, реальные платежи и публикации в каналах не используются для технических проверок. Перед VPS обновлением — отсутствие активных задач, защищённый backup конфигурации и SQLite, сравнение прежних данных и возможность вернуть старый код. После — правильный commit, systemd/runtime/API readiness. Результаты приёмки в отдельном отчёте со статусами выполнено/ожидает.

## CR-010: компактный диалог и загрузка в студии

Бренд интерфейса — «Образ ·», существующий username пока сохраняется. Сообщения Step1–3 и ожидания относятся к конкретной заявке; после подтверждённой доставки готового файла бот удаляет только собственные служебные сообщения этой заявки. Исходные фото, описания пользователя, ошибки/условия и результат остаются. Ошибка удаления не вызывает повторный Image-вызов, новое списание или потерю готового результата. История до обновления автоматически не очищается.

Для всех шести функций Step2 содержит соответствующее описание и короткий копируемый пример. Step3 разделяет функцию, описание и расход попытки пустыми строками; обычные эмодзи используются умеренно. Нижняя клавиатура сохраняет действия, большая часть кнопок нейтральна, зелёный выделяет полезные действия, синий используется ограниченно. Mini App сохраняет существующую компоновку и точку в логотипе; основной цвет — спокойный бирюзовый.

Выбор фото в Mini App не зависит от остатка попыток. Первая кнопка работает после пользовательского нажатия, состояние подключения/согласия понятно; выбранный файл не теряется при завершении авторизации. Серверная загрузка требует подписанного входа и согласия. Модель, качество medium, кошелёк и три trial-попытки сохраняются. Качество вывода и будущая водяная метка описываются отдельной запиской; автоматический платный PoC не запускается.

Ограничение очистки: ID служебных сообщений хранятся в памяти процесса с лимитами1000заявок/100ID/24часа. При перезапуске посреди заявки или превышении лимита прежние шаги могут остаться; произвольные ID и чужие сообщения не угадываются. Остаток попыток и история результатов по-прежнему постоянны в SQLite.

## CR-011: нейтральная клавиатура и демонстрация покупки

Нижняя клавиатура использует стандартный цвет Telegram; только «Поддержка» зелёная. Добавлена «Купить / продлить доступ». Поддержка показывает прямую URL-кнопку на @nedelsky. Покупка редактирует одно сообщение: Express 150 ₽ / Базовый 350 ₽ / Premium 850 ₽ → СБП / Крипта → демонстрационная ссылка, выбранная цена, документы и отмена. Количество генераций и срок доступа ещё не определены; три цены предварительные.

В текущей версии это только интерфейс демо: нет счёта у провайдера, настоящей оплаты и начисления доступа. 60 минут — срок демо-сессии. Кошелёк, фотографии и выполняемые генерации не меняются. Реальные продажи цифровых услуг в Telegram требуют Stars, включая сценарии с внешними платёжными страницами; Platega не подключается для приёма платежей внутри этого бота. Платёжный контракт и ссылки: `payment-demo.md`.

Дополнение CR-011: нижнюю клавиатуру можно вручную скрывать и открывать штатным значком Telegram. Принудительное закрепление и автоматическое скрытие после выбора отключены; цвета и кнопки покупки сохраняются.


## CR-012 — панель владельца и фото на документы, 08.10.2026

Владелец запросил /admin только по своему Telegram ID: постоянный список всех пользователей, реальные покупки и число готовых обработок, кликабельный username/ID. Доступ проверяется по приватно настроенному ADMIN_TELEGRAM_ID и личному чату на каждом действии. Собираем только ID, публичный username и даты посещений; имена/контакты/сообщения не добавляются. Задания и платежный учёт сохраняются после TTL фото и перезапуска. Демо и sandbox не покупки; четыре копии на листе и повторная доставка не умножают генерации. Детали: [admin-panel.md](admin-panel.md).

Функция называется «Фото на документы» по последнему уточнению владельца. Один пункт меню, внутри выбор одежды/подготовки исходника без ИИ. По умолчанию 35×45 мм, четыре одинаковые копии 2×2 на PNG 826×1062/300 DPI, одна попытка. ИИ-вариант вызывает Flare один раз; исходник только кадрируется без OpenAI. Приём паспортным ведомством не гарантируется; ограничения и источники: [document-photos.md](document-photos.md). Существующие модель, шесть функций, бесплатный лимит три, объединение за одну trial-попытку и отключённая реальная оплата сохранены.

## CR-013 — подсказки о количестве причёсок, 09.10.2026

В шаге описания причёски Telegram и Mini App показывают рекомендуемый диапазон запроса 1–12 вариантов на одном изображении. Примеры для 1, 9 и 12 копируются/вставляются без запуска и расходования попытки. Один готовый коллаж — одна попытка, провайдер сохраняет `n=1`. Пользователь видит оговорку о меньшем размере портретов и возможном отклонении числа вариантов; диапазон не выдаётся за ограничение API или проверенную гарантию качества. Детали: [photo-variants.md](photo-variants.md).

## CR-014 — тестирование владельца и отложенная программа роста, 09.10.2026

Безлимит количества генераций включается только для приватно настроенного ID владельца. Не изменяет его баланс и прежние trial-счётчики, сохраняет серверный учёт готовых результатов, согласие, владение медиа, одну активную задачу и идемпотентность. Флаг фиксируется в новой задаче; старые задания завершаются по прежнему учёту. Детали: [owner-testing.md](owner-testing.md).

Реферальные ссылки и схема «две бесплатные плюс одна за подписку на два канала» пока не реализуются. Размер награды после оплаты приглашённым — три или пять генераций — требует расчёта экономики. После подключения и проверки реального платежа напомнить владельцу об этих функциях. Текущий лимит остальных пользователей остаётся три. [Отложенные пожелания](growth-backlog.md).
