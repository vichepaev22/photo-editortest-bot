# После подключения оплаты

Статус: актуализировано 09.10.2026. Каждому новому пользователю положена **одна** базовая бесплатная генерация; владелец отдельно получает безлимит тестирования. По новому прямому поручению бонус за каналы реализуется сейчас, реферальная программа остаётся следующим этапом после проверки реальных платежей.

После готового результата первой базовой генерации бот предлагает ещё одну бесплатную генерацию за подписку на **@FutureDarkSide** и **@nofuturenews**. Сообщение содержит ссылки на оба канала и кнопку «Проверить подписку». Бот проверяет обе подписки через Telegram API; при отсутствии подписки указывает нужные каналы, при недоступности API ничего не начисляет. При подтверждении добавляет **ровно одну** генерацию один раз за всё время. Перезапуск, повторная проверка, выход из каналов и повторная подписка не обновляют бонус. Проверка также доступна через «Мои попытки» и `/bonus`. Бот должен быть администратором обоих каналов.

Подарочные генерации дополняют базовую попытку, а не отменяют её. Бонус за каналы также доступен пользователям с подарком; конечный остаток не превращается в безлимит. Предложение после результата отправляется максимум один раз; при ошибке его отправки проверка остаётся доступна через меню.

Когда реальная оплата подключена и проверены платёж, подтверждение и начисление, напомнить: **«Максим, мы хотели добавить ещё эти функции»** — и предложить реализацию следующих пунктов:

- Персональная реферальная ссылка каждого пользователя.
- Ранее обсуждавшиеся две бесплатные генерации при входе заменены актуальным правилом: одна базовая и одна дополнительная за подтверждённую подписку. Бонус за каналы вынесен из отложенных задач и внедряется сейчас.
- Реферальная награда пригласившему только после подтверждённой реальной оплаты приглашённым пользователем хотя бы минимального тарифа. Переход по ссылке, регистрация, демо и тестовый платёж сами по себе награду не дают.
- Размер награды пока не выбран: обсуждаются три или пять генераций. Перед выбором рассчитать экономику с себестоимостью обработки, комиссией, сервером, бесплатными бонусами и возвратами; не обещать заведомо убыточный бонус.

На следующем этапе определить одноразовость реферальных наград, обработку возвратов и защиту от самоприглашения и повторного начисления. Сейчас не создавать реферальные ссылки, таблицы и начисления. Автоматическое уведомление на конкретное время не настроено: напоминание привязано к этапу подключения оплаты.
