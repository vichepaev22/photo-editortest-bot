# Развёртывание на VPS

Проверено 2026-10-08. Основной Telegram-бот перенесён на Play2go VPS:
Ubuntu 26.04, x86_64, 2 CPU, около 4 GB RAM и 60 GB диска. Процесс
`image-studio-bot.service` работает от отдельного пользователя `image-studio`,
автоматически запускается после загрузки сервера и перезапускается при сбое.
Компьютер владельца больше не нужен для работы бота. Локальный poller остановлен.

Модель сохранена: `gpt-image-2.5-flare-2026-09-08`, medium, 1024×1024.
Три бесплатных успешных результата выдаются один раз на пользователя.
Объединение двух фото и каждый новый вариант используют по одной попытке.
Коммерческие платежи отключены.

## Проверенный перенос

Локальный бот остановлен при отсутствии queued/running задач. Экспортёр
`deploy/vps/export_state.py` сделал согласованный SQLite backup и архив media.
Исходная база и фотографии сохранены для отката. Только в копии исправлены
разделители Windows в разрешённых путях владельцев; время изменения фото
сохранено, поэтому перенос не продлевает их срок хранения.

На сервере проверены SHA256 архива и БД, целостность SQLite, совпадение всех
строк таблиц с ожидаемой копией и времени изменения файлов. Существующие
согласия, история, финансовый баланс и использованные trial-попытки сохранены.
SSH-ключ сервера закреплён локально; секреты переданы отдельно от исходников.

Настройки: `/etc/image-studio-bot.env`, root:root, 0600.
Код: `/opt/image-studio-bot/app`, root-owned.
Данные: `/var/lib/image-studio-bot/live-pilot`, доступ только сервисному пользователю.
Runtime lock: `/opt/image-studio-bot/app/data/runtime`.
Python приложения: 3.12.15, установлен отдельно через uv 0.12.23 под `/opt`.
Системный Python 3.14 не используется приложением.

## Установка на новый сервер

`deploy/vps/install.sh <published-40-character-commit>` готовит свежий Ubuntu
24.04/26.04 и не запускает бот. При существующей установке скрипт прекращает
работу. После установки отдельно передаются приватные настройки и проверенный
снимок; затем разрешён запуск единственного poller.

GitHub Pages размещает интерфейс, а серверный API слушает только
`127.0.0.1:8089`. Публичный HTTPS настраивается отдельным
`deploy/vps/setup-https.sh <public-IPv4>` для свежего Ubuntu 26.04 x86_64.
HTTP обслуживает только ACME challenge; HTTPS проксирует `/api/`, включая
проверку Telegram initData и владения данными в приложении. Публичные demo
маршруты закрыты. Секреты и фотографии не входят в Pages.

Let’s Encrypt выпускает сертификаты на IP сроком шесть дней; Certbot 5.8.0
использует webroot и профиль shortlived. Скрипт создаёт таймер проверки
продления каждые 12 часов и reload-hook для Nginx.
[Официальная инструкция](https://letsencrypt.org/2026/03/11/shorter-certs-certbot).

## Обслуживание через SSH

```sh
systemctl status image-studio-bot --no-pager
systemctl stop image-studio-bot
systemctl start image-studio-bot
systemctl status image-studio-certbot-renew.timer --no-pager
```

Остановленный экземпляр на компьютере нельзя запускать одновременно с сервером.
Для отката сначала остановить серверную службу; перед возвращением на компьютер
нужен новый согласованный снимок, иначе потеряются действия пользователей,
выполненные после переноса. Локальный снимок переноса хранится приватно; это
резерв на момент миграции, а не автоматическая внешняя backup-служба.

Проверки не вызывали платную генерацию Image. Проверены сеть, модель, состояние
и запуск; качество нового результата проверяется пользовательским тестом в боте.

## Документация провайдера

Пользовательская ссылка [«Хостинг»](https://play2go.wiki/host/) описывает другой
тип размещения. Для этого сервера применимы [VDS](https://play2go.wiki/vds/),
[SSH](https://play2go.wiki/vds/ssh) и [SSH-ключи](https://play2go.wiki/vds/sshkeys).
Доступ к Telegram/OpenAI установлен реальной проверкой с VPS. Наличие backup
провайдера или лимиты конкретного тарифа по wiki не подтверждены.
