## Подсветка и ограничение Telegram

[RichMessageButton](https://core.telegram.org/bots/api#richmessagebutton) и [InlineKeyboardButton](https://core.telegram.org/bots/api#inlinekeyboardbutton) поддерживают готовые стили. В документации нет CSS/shimmer/произвольного градиента. Реализован один конечный проход штатного success: очки → причёска → ещё → студия → инструкция. Одновременно выделена только одна кнопка, предыдущая возвращается к теме клиента; последний кадр нейтральный. Цвет определяется Telegram/темой, плавное переливание не заявляется. 2секунды между кадрами, до6edit/примерно12секунд; максимум3прохода одновременно на процесс. Никакого бесконечного мигания, автокликов или новых сообщений от подсветки.

Rich редактируется как rich_message, fallback — как inline reply markup. callback_data и URL сохраняются. Ввод/нажатие и shutdown отменяют декоративные задачи. При429/неопределённой сети дальнейшая подсветка прекращается без быстрых повторов; нейтральное восстановление best effort. [Лимиты Telegram](https://core.telegram.org/bots/faq#my-bot-is-hitting-limits-how-do-i-avoid-this), middleware сверено через Context7 для aiogram3.31.0.
