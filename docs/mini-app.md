# Как проверить студию

Для локального DEMO запустить scripts/Start-Bot.ps1 -Mode Demo и открыть http://127.0.0.1:8089/ . bot, Image worker и API работают в одном процессе. API слушает только loopback; порт задаётся STUDIO_PORT (по умолчанию8089). STUDIO_ENABLED=false отключает интерфейс при следующем запуске.

В обычном браузере явно подтвердить согласие и открыть тестовую студию. Это отдельный пользователь с тремя тестовыми попытками один раз. Баланс Telegram-пользователя не затрагивается. Новый пользователь Telegram входит через подписанный initData; сервер никогда не принимает имя/ID из непроверенных полей.

Выбрать одну из шести функций, загрузить одно фото (два для объединения), написать описание. Перед отправкой студия показывает стоимость1/2 и остаток. Только явное подтверждение создаёт задание. В DEMO результат — помеченная копия исходника, без ИИ-правки. Во вкладке «Результаты» доступны скачивание и сравнение; повторное скачивание не создаёт Image-запрос. Сравнение с исходником доступно для фото этой браузерной сессии, после полной перезагрузки остаётся скачивание результата.

При неизвестном исходе отправки интерфейс предлагает повтор с прежним ключом, не автоматический новый запрос. После прерывания provider задача требует поддержки; автоматической повторной генерации нет. При удалении данных показывается подтверждение; активная задача блокирует удаление. Фото и результаты доступны24часа; финансовая запись остаётся.

На публичной Pages-странице без HTTPS API работает предпросмотр. Можно выбрать фото только в памяти вкладки, функцию и описание, увидеть будущее подтверждение. Загрузки на сервер, баланс и генерация там отсутствуют. Кнопка «Студия» в Telegram открывает этот же предпросмотр; до VPS редактирование проходит через сообщения нативного бота.

Подключение сервера описано в [github-pages.md](github-pages.md), материалы владельца — в [design-assets-brief.md](design-assets-brief.md), протокол — в [mini-app-contract.md](mini-app-contract.md). Секреты нельзя размещать в config.js; там допустим только публичный API-адрес. Перед полноценным запуском остаётся тест на реальных Android/iOS/Desktop клиентах, в том числе Telegram safe areas и загрузка файлов.
