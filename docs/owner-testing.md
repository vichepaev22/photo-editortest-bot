# Безлимитное тестирование владельца

`ENABLE_OWNER_UNLIMITED_TESTING=true` включает исключение только для положительного числового ID из приватного `ADMIN_TELEGRAM_ID`. По умолчанию оно выключено. Конкретный ID и ключи не публикуются. Другие пользователи сохраняют действующие три бесплатные генерации; будущие подписки и рефералы пока только в [плане](growth-backlog.md).

Для каждого нового задания сервер сам определяет `quota_exempt`. Клиентское поле, username, пересланное сообщение или кнопка не включают безлимит. Для владельца в Telegram и авторизованной студии показан безлимит; денежный баланс и история trial не пополняются и не сбрасываются. OpenAI оплачивается с API-баланса обычным образом.

Освобождение от квоты сохраняется в задании: переключение настройки или перезапуск не меняют способ завершения старой обработки. Задания до обновления получают `quota_exempt=0` и учитываются как прежде. Все готовые результаты, включая тестирование владельца, входят в админскую статистику; повторная доставка не увеличивает счётчик.

Согласие, владение фотографией, размер и срок хранения файлов, одна активная обработка на пользователя, блокировка неразобранной задачи и защита от повторного платного вызова сохраняются. Безлимит снимает ограничение количества результатов, а не ограничения API, параллельности или хранения.
