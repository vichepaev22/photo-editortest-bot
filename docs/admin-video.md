# Тестовый видеомонтаж для владельца Telegram

CR-ADMIN-VIDEO-001,23.10.2026. Статус: implemented/offline and synthetic-server verified/deployed; реальный платный тест выполняет владелец.
Главное ТЗ: [PRD.md](PRD.md), раздел CR-ADMIN-VIDEO-001. MAX и Mini App не меняются.

## Как запустить первый тест

1. В личном чате Telegram-бота отправьте `/admin` под аккаунтом владельца3975497.
2. Нажмите **🎬 Видеомонтаж · тест**, при необходимости откройте **Инструкция**.
3. Нажмите **Новое видео**, пришлите обычное видео или файл MP4/MOV/WebM.
4. Ограничения исходника: **19MB,90секунд,до4K**. Для первого опыта удобен ролик15–30секунд. На iPhone отправка обычным видео обычно уменьшает файл; загрузка файлом сохраняет его исходные байты.
5. Если нужна музыка, после видео пришлите свою аудиодорожку MP3/M4A/WAV до5MB. Сначала принимается видео, затем музыка. Без своей дорожки используется исходный звук либо тишина по заданию.
6. Кнопка **Речь: вкл/выкл** управляет распознаванием. Выключите его для ролика без разговора, чтобы не тратить API на музыку.
7. Напишите пожелания (до1500символов). Кнопки **Составить план · платный API** до этого не будет.
8. Нажмите **Составить план**. Это явно запускает OpenAI: до12запросов gpt-transcribe (если есть звук и речь включена) и один gpt-6.1-sol. Код не повторяет запросы автоматически.
9. Изучите план и полученные токены, затем нажмите **Собрать видео · без API**. Придёт MP4 и панель работы.
10. **Скачать MP4** и повторная **Сборка** используют сохранённый план без новых запросов модели. Для нового задания/повторного анализа создайте новую работу; это снова оплачиваемые API-вызовы.

Пример задания:

> Сделай вертикальный ролик до30секунд. Выбери интересные фрагменты, сохрани речь, добавь русские фразовые субтитры, короткий заголовок и плавные склейки. Порядок должен быть логичным.

Пример без речи:

> Собери динамичный ролик до20секунд, квадратный формат. Субтитры не нужны. Используй присланную музыку тихим фоном. Добавь короткий заголовок.

## Возможности и ограничения первого прототипа

- GPT‑6.1 Sol видит выбранные кадры с отметками времени и распознанный текст. Это выборочная раскадровка, а не непрерывный покадровый просмотр.
- FFmpeg готовит до12фрагментов: при включённой речи учитываются обнаруженные паузы; длинные участки делятся. Модель выбирает1–8целых фрагментов в нужном порядке, суммарно до60секунд.
- Форматы: вертикальный720×1280, горизонтальный1280×720, квадрат720×720;30fps,H.264/AAC,MP4. Полный кадр помещается с полями, автоматического слежения/кадрирования по лицу нет.
- Склейки: обычные или короткое плавное появление/затухание у краёв фрагмента. Это не полноценный crossfade.
- Русские субтитры берутся из расшифровки; время фразы распределяется внутри её исходного фрагмента приблизительно. Подсветки отдельных слов и точной синхронизации пока нет. Ошибки ASR возможны.
- Музыка не ищется в интернете и не генерируется. Для микширования нужна ваша аудиодорожка с правами на использование.
- Инструкции про изменение лица/одежды/фона видео, генерацию новых сцен или внешние ссылки этот модуль не исполняет.
- Один процесс одновременно. Выход из раздела не прерывает уже отправленный API-запрос; результат придёт в личный чат. Перезапуск сервиса отмечает прерванную работу для проверки и не повторяет платные вызовы.

## Где смотреть расходы

`/admin → Видеомонтаж → Расходы и работы` показывает последние20работ и сумму только подтверждённых токенов. В карточке — каждый вызов по отдельности. **Отчёт JSON** содержит сохранённый ответ usage без ключей API:

- модель, тип вызова, время, request_id, статус;
- входные/выходные токены, если провайдер их вернул;
- cached и reasoning, если доступны: они уже входят в общий input/output;
- длительность отправленного аудио и сырой usage ASR;
- отсутствие usage/сетевой таймаут отмечаются как неизвестный расход, не ноль.

Готовый ролик, расшифровка, кадры, пожелания и план хранятся24часа с очисткой раз в минуту. После этого доступны только технические квитанции расхода. Фото-генерации и пользовательские тарифы не затрагиваются. Качество/реальная стоимость OpenAI пока не подтверждены: первые настоящие API-вызовы выполняет владелец по этой инструкции.

## Техническая запись

Модели `gpt-6.1-sol` (reasoning medium,max_output_tokens4000,store=false) и `gpt-transcribe`; openai-python2.54.0,max_retries0; aiogram3.31.0. Структурированный JSON проходит серверную проверку индексов/длительности/параметров. Пользовательские строки не исполняются в shell или FFmpeg-фильтрах. CLI вызывается через аргументы subprocess, с ограничениями протоколов/форматов, таймаутами и одним потоком. На VPS установлен FFmpeg8.0.1 с libass/libx264 и шрифтом DejaVu Sans.

Флаг `ADMIN_VIDEO_ENABLED=false` по умолчанию; включается только в защищённом env Telegram. Используется существующий `OPENAI_API_KEY`; новый ключ в чат или Git добавлять не нужно. SQLite журнала: `<DATA_DIR>/admin-video/usage.sqlite3`, файлы в приватных UUID-каталогах рядом. Обычные данные/MAX не копируются и не мигрируют.
