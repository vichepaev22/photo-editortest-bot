# Образ: возможности Telegram и концепция интерфейса

Дата последней проверки: 8 октября 2026. Бот: @photo_editortest_bot.

Статус: исследование, реализованная нижняя клавиатура и локальная Mini App; GitHub Pages показывает предпросмотр до публичного HTTPS API. В OpenAI-пилоте каждому после согласия доступны три генерации один раз, включая объединение по одной. Остальные возможности платформы ниже — обзор и будущие варианты, а не заявление об их реализации в боте.

## Основа исследования

Проверены официальные Bot API, changelog, Bot Features, Bot Guidelines, Mini Apps и анонсы Telegram. Последняя опубликованная версия в проверенном changelog — **Bot API 10.3 от 24 августа 2026**. Среди её изменений: неактивные inline-кнопки, кнопки внутри Rich Messages, сворачиваемые цитаты, документы и события остановки генерации черновика. Это обзор пользовательских возможностей, а не перечень каждого метода API. [Официальный changelog](https://core.telegram.org/bots/api-changelog).

## Оформление кнопок

В нативной клавиатуре Telegram есть заранее заданные цветовые стили. Их отображение учитывает тему клиента. Можно добавить обычный эмодзи в подпись или специальную emoji-иконку. Для специальных иконок действуют условия Telegram Premium у владельца либо дополнительных имён бота через Fragment; для отправки в разные контексты нужно проверять соответствующие ограничения. [Button styles](https://core.telegram.org/api/bots/buttons#button-styles).

| Стиль в Bot API | Цвет | Предлагаемое применение в нашем боте |
|---|---|---|
| `primary` | Синий | Изменить/объединить, помощь/поддержка, inline-выбор и навигация |
| `success` | Зелёный | Мои попытки/результаты, подтверждение генерации |
| `danger` | Красный | Подтверждённое удаление локальных фото |
| Без `style` | Стандартный для клиента | Возможность платформы; у нашего основного меню стили заданы явно |

Значения `style` перечислены в [KeyboardButton](https://core.telegram.org/bots/api#keyboardbutton) и [InlineKeyboardButton](https://core.telegram.org/bots/api#inlinekeyboardbutton). Для нативных кнопок эти типы не предоставляют произвольный HEX-цвет, CSS, шрифт, градиент или радиус скругления. Собственную палитру и вёрстку предлагаем реализовать в Mini App.

Цветные кнопки официально анонсированы 9 февраля 2026. [Анонс Telegram](https://telegram.org/blog/crafting-android-design-and-more).

Наше дизайнерское правило: один заметный основной шаг на экране; текст всегда объясняет действие, даже без цвета. Обычные эмодзи позволяют сделать первую версию узнаваемой без покупки декоративных возможностей. Красный не используем для обычного «Назад».

## Что доступно и как это применить

| Возможность | Подтверждённая функция Telegram | Предложение для «Образа» |
|---|---|---|
| Нижняя клавиатура | Ряды кнопок, компактная высота, запрос постоянного отображения, подсказка в поле ввода. Постоянство — запрос клиенту, а не принудительное закрепление на любом экране. [ReplyKeyboardMarkup](https://core.telegram.org/bots/api#replykeyboardmarkup) | Шесть коротких основных действий; при вводе описания обеспечить удобный доступ к обычной клавиатуре |
| Кнопки под сообщением | Контекстные действия; меню можно обновлять на месте без новых пользовательских сообщений. [Inline keyboards](https://core.telegram.org/bots/features#inline-keyboards) | Выбор функции, назад, подтверждение цены, листание результатов |
| Меню возле поля ввода | Список команд либо запуск Mini App. [Menu Button](https://core.telegram.org/bots/features#menu-button) | Позже — отдельный вход «Открыть студию» |
| Неактивные кнопки | `disabled` у inline-кнопки; новые возможности управления ответом. [Bot API 10.3](https://core.telegram.org/bots/api-changelog) | Показывать недоступный шаг и состояние обработки. Повторное списание также блокировать на сервере |
| Rich Messages | Заголовки, таблицы, встроенные изображения, карусели/коллажи, сворачиваемые разделы. [Анонс Rich Text for Bots](https://telegram.org/blog/watch-apps-and-more) | Карточка примера и результата; на старых клиентах сохранять доступный обычный сценарий |
| Кнопки внутри текста | Несколько интерактивных действий прямо в сообщении, в том числе совместно с персональными ephemeral-ответами. [Анонс 25 августа](https://telegram.org/blog/welcome-messages-buttons-TG-13) | Позже — компактная карточка варианта с действиями рядом с содержимым |
| Потоковые ответы | Обновление текста по мере генерации. [Streaming Text for Bots](https://telegram.org/blog/ai-bot-revolution-11-new-features#streaming-text-for-bots) | Состояния «Фото принято», «Создаём», «Отправляем». Процент готовности показывать лишь при реальных данных |
| Остановка черновика | События остановки и параметры управления черновиком в API 10.3. [Changelog](https://core.telegram.org/bots/api-changelog) | Рассмотреть после проверки отмены задания у провайдера. Остановка отображения сама по себе не доказывает отмену платного запроса |
| Темы личного чата | Разделение диалогов бота на темы, с включением через BotFather. [Topics in Private Chats](https://core.telegram.org/bots/features#topics-in-private-chats) | Позже — отдельные фотопроекты, если истории станет много |
| Mini App | Собственный интерфейс, темы Telegram, полноэкранный режим, безопасные отступы, основные/дополнительные нижние кнопки, тактильный отклик. [Mini Apps](https://core.telegram.org/bots/webapps) | Визуальная примерочная, карточки причёсок и очков, сравнение «до/после» |
| Отправка и скачивание из Mini App | Публикация медиа в чат или Stories по действию пользователя, диалог скачивания. [Mini Apps: media](https://core.telegram.org/bots/webapps) | Сохранить результат или поделиться; исходные фото автоматически не публиковать |
| Ссылки и inline-режим | Переход со стартовым параметром, обращение к боту из поля другого чата. [Deep Linking](https://core.telegram.org/bots/features#deep-linking), [Inline Requests](https://core.telegram.org/bots/features#inline-requests) | Ссылки на конкретную функцию; добровольная отправка выбранного результата |
| Guest Bots | Вызов бота упоминанием в другом чате с ограниченным доступом к контексту. [Guest Bots](https://telegram.org/blog/ai-bot-revolution-11-new-features#guest-bots) | Возможное дальнейшее расширение; для текущих личных фото основной сценарий остаётся в личном чате |
| Ephemeral Messages | Ответ в группе виден конкретному пользователю; персональные меню. [Анонс июля](https://telegram.org/blog/communities-editor-invisible-messages#ephemeral-bot-messages) | Возможность будущего группового режима, отдельно от нынешнего MVP |
| Профиль и примеры | Main Mini App может иметь кнопку запуска, изображения и видео демонстрации. [Main Mini App](https://core.telegram.org/bots/webapps#launching-the-main-mini-app) | Показать реальные согласованные примеры после визуального PoC |

Также официальная платформа охватывает опросы/викторины, чеклисты, Live Photos, создание стикеров, Web Login, бизнес-автоматизацию, managed bots, общение ботов, сообщества и управление каналами. Это отдельные направления, не новые операции редактирования Image. [Каталог Bot Features](https://core.telegram.org/bots/features). Новые опросы, Live Photos и managed bots описаны в [мартовском анонсе](https://telegram.org/blog/ai-editor-mighty-polls-and-more); общение ботов и автоматизация аккаунта — в [майском анонсе](https://telegram.org/blog/ai-bot-revolution-11-new-features).

Вход через меню вложений пока ограничен одобренными ботами; не обещаем его как общедоступную функцию. [Attachment Menu](https://core.telegram.org/bots/features#attachment-menu).

## Предлагаемый интерфейс первой версии

Наша концепция — личная фотостудия с понятными действиями и ценой перед созданием.

Нижняя клавиатура:

| | |
|---|---|
| 📸 Изменить фото | 🧩 Объединить фото |
| 💎 Мои попытки | 🖼 Мои результаты |
| ❓ Как пользоваться | 💬 Поддержка |

По нажатию «Изменить фото» бот показывает под сообщением сетку 2 × 3: причёска, одежда, очки, фон, улучшение, объединение. Каждая функция имеет короткое объяснение и один пример. Внутри сценария всегда есть «Назад» и «Главное меню».

Telegram в своих guidelines рекомендует inline-клавиатуры для меню, а reply-клавиатуры для предопределённых ответов. Нижняя панель из шести действий — наше предложение с учётом прямого пожелания владельца; вложенные списки и настройки используем под сообщением. [Bot Guidelines](https://core.telegram.org/bots/guidelines#2-3-custom-keyboards).

Предлагаемый сценарий:

1. **Выбор** — «Что хотите изменить?» и кнопки функций.
2. **Фото** — «Пришлите фото: лицо хорошо видно, без сильного размытия». Для объединения: «Фото 1 из 2», затем «Фото 2 из 2».
3. **Описание** — короткий пример запроса и возможность написать свой вариант. Кнопки навигации обрабатываются отдельно от описания.
4. **Подтверждение** — «Причёска: каре до плеч. Стоимость: 1 попытка. После операции останется 2». Зелёная кнопка «Создать · 1 попытка», нейтральные «Изменить описание» и «Назад». Для объединения указать 2 попытки.
5. **Ожидание** — одно обновляемое сообщение с фактической стадией и номером задания. Без выдуманного процента готовности.
6. **Результат** — фото для просмотра и файл результата; действия «Ещё вариант · 1 попытка», «Новая правка», «Мои результаты». Каждый новый платный вариант снова проходит подтверждение.

У списка результатов учитывать существующий локальный TTL 24 часа. Повторная доставка готового файла не вызывает Image повторно. Баланс и помощь не должны превращаться в описание правки или уничтожать введённые данные.

## Видение Mini App

Следующая ступень — кнопка «Открыть студию» в том же боте. Предлагаем четыре раздела: **Студия · Образы · Результаты · Профиль**. В студии — большое исходное фото, выбранная функция, параметры и одна заметная кнопка с ценой. В «Образах» — визуальные варианты; в результатах — сравнение и сохранение.

Карточки с миниатюрами, ползунок «до/после», выбор длины волос или оправы — наши компоненты на HTML/CSS/JavaScript. Telegram предоставляет среду Mini App, а не готовый редактор фотографий. Для настоящего приложения понадобится HTTPS-адрес; текущему локальному polling-боту он не нужен. [WebAppInfo](https://core.telegram.org/bots/api#webappinfo), [Implementing Mini Apps](https://core.telegram.org/bots/webapps#implementing-mini-apps).

Визуальное направление: крупные фотографии, короткие подписи, спокойные поверхности и свободное пространство. В Mini App можно предложить фирменный фиолетовый акцент, например #7C3AED, сохранив цвета темы Telegram для фона и текста. Светлая и тёмная темы, контраст, подписи и отступы важнее декоративных эффектов. Это наша палитра-предложение, не обещание HEX-цвета нативным кнопкам. Telegram рекомендует мобильную адаптацию, доступные подписи, соответствие теме и safe area. [Designing Mini Apps](https://core.telegram.org/bots/webapps#designing-mini-apps).

Фирменные логотип, обложка и примеры должны показывать смысл сервиса. Liquid Glass и оформление самого Telegram контролирует клиент; собственные эффекты Mini App проектируются отдельно. Для новых Rich Messages заранее предусмотреть обычные сообщения, если клиент не умеет отображать новый формат: Telegram описывает заглушки обновления приложения в [последнем анонсе](https://telegram.org/blog/welcome-messages-buttons-TG-13#placeholders-for-app-updates).

## Последовательность продолжения

1. Реализовать нижнюю навигацию, сетку функций, цвета, помощь и понятное подтверждение стоимости.
2. Проверить на Android, iOS и Desktop: светлая/тёмная тема, длинные русские подписи, возврат к вводу текста, повторные нажатия и восстановление результатов.
3. Добавить Rich Messages и неактивные состояния с обычным запасным сценарием.
4. После проверки качества Image — визуальные примеры и Mini App-примерочная.
5. Расширять обмен результатами, ссылки и проекты по подтверждённой потребности пользователей.

Текущий установленный aiogram **3.31.0** проверен локально: `KeyboardButton` содержит `style` и `icon_custom_emoji_id`; `InlineKeyboardButton` — также `disabled`; `ReplyKeyboardMarkup` — `is_persistent`, `resize_keyboard`, `force_reply`. Это проверка типов SDK, не проверка отображения на устройствах. Тесты программы в этом документальном этапе не запускались.

Платёжный UX не переключаем автоматически. Выбранный sandbox ЮKassa сохраняется. Официальная документация требует Stars для продажи цифровых услуг внутри Telegram; этот уже зафиксированный вопрос остаётся отдельным решением перед продажами. [Digital goods payments](https://core.telegram.org/bots/payments-stars#q-can-i-use-a-different-currency-or-payment-provider).

Исследование и дизайн-предложение оформлены в рамках process-design-vibecoding. После принятия владельцем выполнен срез интерфейса ниже; остальные исследованные возможности остаются планом.

## Реализованный срез 2026-10-07

В нативном боте: постоянная компактная нижняя клавиатура3×2, inline-сетка функций, semantic style для главного/подтверждающего/удаляющего действий, стоимость перед отправкой, помощь и баланс без потери черновика, список и повторная выдача собственных результатов. Для обновления клавиатуры в существующем чате отправить `/start`.

Mini App: четыре вкладки, одно/два фото, выбранная функция и описание, подтверждение, состояние задачи, файл, сравнение, профиль и удаление. Светлая/тёмная темы; Telegram bridge имеет проверки версии, safe area учитывается. Локальное DEMO проверено браузером; отображение конкретных кнопок в Android/iOS/Desktop остаётся устройственным тестом. Rich Messages, custom emoji Premium, sharing и новый редактор Telegram не заявляются реализованными.

GitHub Pages даёт HTTPS-адрес статическому предпросмотру. Настоящая генерация внутри Mini App подключается после размещения API на VPS; нативный бот уже использует локальный worker. Иллюстрации и примеры готовит владелец по [ТЗ](design-assets-brief.md).

## Дополнение 2026-10-08

Нижняя клавиатура сохраняет шесть действий и layout 3×2: первый ряд синий, второй зелёный, третий синий. У выбора функций и inline-навигации задан синий стиль по умолчанию; подтверждение генерации остаётся зелёным. Чтобы получить новую клавиатуру в существующем чате, отправить `/start`. SDK поддерживает эти параметры; фактическое отображение проверяется на клиенте владельца.

Новые направления платформы: Rich Messages с карточками/коллажами/таблицами и вложенными кнопками; streaming drafts с событием Stop; приватные ephemeral-ответы в группах; гостевые боты и взаимодействие ботов; темы личного диалога. [API 10.3 и changelog](https://core.telegram.org/bots/api-changelog), [Bot Features](https://core.telegram.org/bots/features). Это кандидаты для отдельных сценариев, а не автоматическое изменение нашего private-only MVP.

В Mini App можно развивать fullscreen, собственную CSS-палитру, native sharing/download/Stories, haptic feedback, MainButton/SecondaryButton, QR, геолокацию, биометрию, датчики и DeviceStorage/SecureStorage. Наличие функции проверяется по версии/возможностям клиента; действия с личными данными и публикацией требуют действия пользователя. OpenAI API-ключ всегда остаётся на backend, даже при наличии SecureStorage. [Mini Apps](https://core.telegram.org/bots/webapps).

6 октября Telegram добавил размещение Mini App и вызов endpoints в [Telegram Serverless](https://core.telegram.org/bots/serverless): JavaScript-модули, встроенная БД и внешний HTTP. Для нашего Python-проекта нужны отдельная адаптация и проверка условий, включая секреты, атомарность, долгий Image-вызов и фото. Документация не подтвердила нулевую цену и достаточные runtime-квоты, поэтому это не объявляется бесплатным переносом. Подробный выбор платформы: [hosting-options.md](hosting-options.md).
## Уточнение бесплатного чата после первого теста

Шаг 1 объясняет загрузку файла JPEG/PNG/WebP до10 MB, затем отдельной строкой предлагает сделать фото сейчас на нейтральном фоне, например у стены. Если прежний исходник ещё доступен, показываются «Использовать загруженное фото» и «Загрузить новое». Ответ на собственное фото в этом же личном чате тоже выбирает исходник. После описания в бесплатном чате шаг 3 сообщает функцию и расход одной попытки и сразу запускает задачу.

Во время ожидания и обработки используется нативный `sendChatAction` с `upload_photo`, обновляемый каждые4секунды: Telegram сохраняет статус не более5секунд и снимает его при новом сообщении бота. Это активность, не измерение процента готовности. Обычные сообщения не содержат job ID. Готовый файл можно «Скачать ещё раз» без новой генерации; список собственных результатов доступен24часа. [sendChatAction](https://core.telegram.org/bots/api#sendchataction), [Message.reply_to_message](https://core.telegram.org/bots/api#message).
