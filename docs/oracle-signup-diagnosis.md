# Ошибка регистрации Oracle Cloud

Проверено 2026-10-08: только официальные источники, без повторной регистрации или обращения в поддержку.

## Наблюдаемый факт

Наблюдался общий отказ создания аккаунта, без указания конкретного ошибочного поля. Личные, платёжные и региональные сведения регистрации остаются локально и в публичную записку не включаются. После отображения подтверждённой карты создание аккаунта завершилось общим отказом. Сообщение перечисляет неточные сведения, скрытие идентификационных данных/местоположения и попытки нескольких аккаунтов; доступны Retry и Contact Oracle Support. Это перечень возможных причин, а не подтверждение конкретного нарушения. Подтверждение карты на форме не гарантирует окончательного одобрения регистрации, в том числе антифродом, и не доказывает создание OCI tenancy. Это вывод по наблюдаемому результату, а не установленная причина отказа.

## Подтверждённые правила

- Разрешён один Free Trial или Always Free аккаунт на человека; попытки нескольких бесплатных аккаунтов запрещены. Контактные и billing сведения должны быть достоверны, действительны и использоваться с согласия владельца. Принимаются кредитные карты и дебетовые, работающие как кредитные; не принимаются PIN-debit, виртуальные, одноразовые и предоплаченные карты. При проблемах signup/signin Oracle направляет в Cloud Support Chat. Если нужной страны нет в списке, Oracle предлагает обратиться в Sales/Cloud Support. [OCI Free Tier FAQ](https://www.oracle.com/cloud/free/faq/).
- Home region определяет расположение tenancy и IAM; изменить его после создания tenancy нельзя. Выбор Ashburn сам по себе не устанавливает страну проживания или billing country. [Managing Regions](https://docs.oracle.com/en-us/iaas/Content/Identity/regions/managingregions.htm).
- Для доступа в OCI нужны правильные tenancy/cloud account name, identity domain и пользователь. Данные находятся в activation/welcome email; при потере пароля есть Forgot Password?, при отсутствии письма — поддержка. [Troubleshooting Signing In](https://docs.oracle.com/en-us/iaas/Content/GSG/Tasks/signinginIdentityDomain.htm).

## Гипотезы, требующие фактов

1. Повторный бесплатный аккаунт возможен, только если ранее действительно была создана OCI Free Trial/Always Free tenancy. Слова «существующий Oracle аккаунт» недостаточно: надо отличить профиль Oracle от cloud tenancy.
2. Несовпадение страны не установлено. Менять действительные сведения для обхода отказа нельзя. Ошибки можно установить только при предметной проверке владельцем или по ответу Oracle.
3. Причина, связанная с неподдерживаемой картой, не установлена. Видимый успешный этап проверки не объясняет итоговый отказ и не подтверждает полное одобрение антифродом.
4. Наличие сетевого посредника само по себе не устанавливает причину отказа. Внутреннее решение проверки Oracle из браузера неизвестно.

## Минимальное исправление

Ведущий агент раскрыл адресную форму и проверил только заполненность и validity полей: все обязательные поля заполнены, явных ошибок встроенной проверки не видно. Личные значения не записывались в отчёт. Такая проверка не подтверждает достоверность адреса для банка или решение Oracle; конкретного поля, которое можно обоснованно исправить, не найдено.

Оставшийся вопрос к владельцу: была ли раньше создана OCI Free Trial/Always Free tenancy. Проверенные владельцем сведения повторно запрашивать не требуется; их значения в публичный отчёт не включены. Пока статус прежней tenancy не установлен, не нажимать Retry и не создавать дополнительные бесплатные аккаунты.

Если tenancy уже есть, перейти в [Cloud Sign In](https://www.oracle.com/cloud/sign-in.html) и использовать существующий cloud account name. Там есть Forgot your cloud account name?; восстановление и ввод секретов выполняет владелец. Ведущий агент может открыть страницу, но не должен менять credentials без отдельного поручения.

Если впоследствии обнаружена конкретная ошибка данных, исправить её на действительные сведения. Сейчас оснований для смены страны или региона нет. Если данные корректны, причина и возможность завершить регистрацию требуют ответа Oracle. Кнопка Contact Oracle Support соответствует официальному маршруту: [Contact us](https://www.oracle.com/corporate/contact/) → Open a live chat → Get Support → Cloud Infrastructure (OCI) including Free Trial → Cloud Support Chat. Ведущий агент может подготовить обращение; отправка остаётся за пользователем либо требует его явного поручения.

Текст для самостоятельного обращения: «После подтверждения карты регистрация OCI Free Tier завершилась общим отказом с перечислением возможных причин. Прошу уточнить, требуется ли восстановить существующую tenancy или исправить сведения регистрации, и сообщить разрешённый следующий шаг». Факты о наличии tenancy добавляет владелец. Не прикладывать пароль, номер карты или verification URL.

Самостоятельно нельзя подтвердить сработавшую причину проверки, снять отказ или гарантировать успешный Retry. Регистрация и доступ в OCI в этой проверке не подтверждены.
