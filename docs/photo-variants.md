# Несколько образов в одном изображении

Проверено по официальным источникам 2026-10-08. В Images API `n` задаёт количество **отдельных выходных изображений**; это не раскладка ячеек. Текущий провайдер проекта использует `images.edit`, `n=1`, 1024×1024, medium. [OpenAI Image generation](https://developers.openai.com/api/docs/guides/image-generation).

Предлагаемый эксперимент: описанием попросить один коллаж 3×3 (9 причёсок) или 3×4 (12 оправ очков). Это наша интерпретация возможностей генерации по описанию, а не документированный специальный режим или гарантированная сетка. По правилам проекта один готовый выходной файл расходует одну попытку. Увеличение `n` создаёт отдельные выходы и меняет затраты; автоматически этого не делаем.

Для теста на подписке ChatGPT вместе со своим фото:

> Сделай одно изображение: сетку 3×3 из девяти портретов человека с приложенного фото. В каждой ячейке разная причёска: каре, боб, пикси, длинные прямые волосы, волны, кудри, каскад, чёлка и собранные волосы. Сохрани узнаваемость лица, возраст, выражение, ракурс, одежду и нейтральный фон. Ячейки одинаковые, без текста и рамок. Не создавай девять отдельных файлов.

Для очков заменить сетку на3×4 и перечислить12разных форм/цветов оправ. Число ячеек и сходство обязательно оценивать глазами. При1024×1024 ячейка3×3 примерно341×341; сетка3×4 —341×256. Это расчёт, не измерение качества. OpenAI отмечает ограничения стабильности персонажей и точности сложной композиции. [Ограничения GPT Image](https://developers.openai.com/api/docs/guides/image-generation#limitations).

Отдельная кнопка коллажа, изменение размера и выбор одного варианта пока не реализованы. Увеличенный вывод/параметры качества требуют отдельного сравнения затрат. Платных Image-вызовов для этого исследования не выполнялось; примеры изображений предоставляет владелец.
