## Пользователь

«Купить / продлить доступ» → Express240 ₽/20, Базовый480 ₽/50 (40+10 бонусных),
Premium720 ₽/75 (60+15 бонусных) → СБП либо крипта → ссылка → автоматическое подтверждение.
СБП зелёная, крипта синяя; правовые ссылки нейтральные внизу. Один экран
редактируется, состояние сохраняется в SQLite и переживает перезапуск.
Есть проверка статуса, назад, отмена экрана и поддержка. Отмена экрана не
означает отмену уже проведённого перевода. Количество попыток не имеет нового
срока сгорания; автоматические списания и подписки не подключаются.

Срок ссылки берётся из expiresIn, при его отсутствии срок показывается у
провайдера. Фиксированные 60 минут не обещаются. Return URL только объясняет
статус и предлагает вернуться в бот; само открытие страницы не начисляет доступ.

## Контракт

Готовый Callback URL:
`https://31.76.80.185/api/payments/platega/callback`

Метод POST, публичный HTTPS с доверенным сертификатом. В кабинете Platega:
«Настройки → Callback URLs». Это адрес для сервера Platega, не для покупателя.
Без обоих корректных заголовков X-MerchantId/X-Secret возвращается 404.
Путь активен на VPS. 16.10.2026 владелец сообщил, что сохранил адрес в кабинете Platega. Доставка настоящего уведомления провайдера пока не проверена. Result URL:
`https://31.76.80.185/api/payments/platega/result`.

POST /transaction/process вызывается только после выбора человеком метода;
пакет, сумма, RUB, владелец и orderId/payload фиксируются сервером. metadata
содержит Telegram userId для антифрода и техническую метку вместо имени/фото.
Обработка фото и платёжные данные не отправляются друг другу.

GET /transaction/{id} проверяет transactionId, merchantId/mechantId, RUB,
точную сумму и payload собственного заказа. CONFIRMED начисляет пакет один раз
с unique charge/order, даже при повторе callback/проверке/перезапуске.
Новый платёж конвертирует неиспользованный стартовый доступ в дополнительный
без потерь. При активном trial-резерве конвертация ждёт результата/ошибки;
резерв остаётся видимым, неудавшаяся стартовая генерация возвращается.
Регулярные бесплатные остатки, платные резервы и unlimited владельца сохраняются.

Создание заказа сериализуется durable state ready→creating→pending. У API нет
подтверждённого контракта Idempotence-Key: timeout/неопределённый POST не
повторяется автоматически, creating после рестарта становится uncertain.
Ранний callback может восстановить привязку по проверенному каноническому payload.
Повторный выбор пользователем — отдельная покупка, не невидимый повтор запроса.

Сверка pending GET раз в минуту дополняет callback (до 48 часов), новый callback
и ручная проверка работают позднее. CANCELED не начисляет. CHARGEBACKED
блокирует новый расход и создаёт событие владельцу для разбора; автоматический
банковский возврат не запускается. Для снятия блокировки нужен разбор оператором.

Уведомление об оплате пользователю идёт через отдельный outbox (receipt в том же
окне либо отдельное сообщение, если окно закрыто). Неопределённая доставка не
повторяется; 429 допускает ограниченные повторы после retry_after. Владельцу
приходит существующее событие настоящей оплаты. Доставка не условие начисления.

## Данные и эксплуатация

Три аддитивные таблицы: platega_orders, platega_sessions, platega_notices.
invoices/payments сохраняют текущий финансовый учёт, история не очищается.
Пакеты Platega совпадают с текущим экраном; старый PACKS/YooKassa sandbox не
является источником тарифов реальной покупки. Флаги независимы:
PLATEGA_ENABLED и прежний BILLING_ENABLED; одновременно включать их нельзя.

Реквизиты: локально data/runtime/platega-access.env с owner+SYSTEM ACL,
на VPS /etc/image-studio-bot.env с mode0600. Ключи не идут в Git, JavaScript,
аргументы процессов, логи и ответы API. До переноса backup и проверка отсутствия
активных генераций; миграция должна сохранить все прежние строки/медиа/настройки.

Ограничение Telegram на Stars для цифровых услуг остаётся применимым и к внешней
форме. Владелец уведомлён и явно выбрал Platega. Это не подтверждение соответствия
правилам Telegram. Документ фиксирует решение и технический контракт.
