# Переезд в @obraz_photo_bot

Новый адрес проекта: [@obraz_photo_bot](https://t.me/obraz_photo_bot). Сервер, студия на GitHub Pages, модель и ключ OpenAI остаются прежними. Токен Telegram хранится только в приватном окружении; локальный launcher использует имя бота из `.env`.

При переключении сохраняются пользователи, согласия, кошелёк, история обработок и покупок, статистика `/admin` и неистёкшие файлы. Прежняя переписка остаётся в чате старого бота; пользователю нужно открыть новый бот и нажать «Начать». Владелец сохраняет безлимитное тестирование и доступ к админке.

Обычным пользователям один раз обновляется лимит: три бесплатных результата. У новых пользователей также три; повторный запуск миграции не восстанавливает уже использованные после переезда попытки. Одно готовое изображение, включая объединение или лист фото на документы, расходует одну попытку. Согласие и остальные правила работы сохраняются.

Перед переключением останавливается единственный процесс, проверяется отсутствие активных и неразобранных задач, создаются приватные резервные копии БД, окружения и медиа. Обновляется только использованная бесплатная квота, записывается событие миграции; история и платный баланс не меняются. Нативные заявки получают ключ с ID бота, чтобы одинаковые номера сообщений в двух чатах не конфликтовали.

Ссылка на студию и HTTPS API остаются прежними. После смены Telegram-токена нужно открыть студию заново из нового бота: старый подписанный вход больше не действует. Срок хранения фотографий не продлевается миграцией; истёкшие файлы не восстанавливаются.

Подписки на каналы, рефералы и реальная оплата в эту поставку не входят. Итог фактического запуска и проверки фиксируется в [verification.md](verification.md).
