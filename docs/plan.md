## Где работает бот

Сейчас bot/worker/API работают на Play2go VPS под systemd. Локальный экземпляр остановлен; компьютер владельца больше не нужен. История, фото и использованные trial-попытки перенесены со сверкой всех строк базы. GitHub Pages размещает интерфейс; API доступен через доверенный HTTPS на сервере. Детали и команды обслуживания — в [vps-deployment.md](vps-deployment.md).

Реализованный пилот: Telegram и Pages Mini App ↔ один процесс bot/worker/studio API на Linux VPS ↔ OpenAI API. На VPS находятся SQLite и временные фото. Long polling Telegram работает без webhook; Mini App использует Nginx HTTPS к loopback API. Платёжный модуль остаётся выключен до отдельного коммерческого запуска.

Технический ориентир VPS: 1–2 vCPU, 2 GB RAM, 20 GB диска, без GPU. Это оценка, не измеренная потребность. Провайдера, регион и тариф выбираем по доступности API и нагрузке; сервер не входит в $10 на API.

Перенос выполнен: один polling-процесс, автозапуск, согласованный backup ledger, проверка восстановления, квота и TTL фото. SQLite остаётся для малого однопроцессного пилота; масштабирование БД/очереди решается отдельно.

## Что нужно от владельца

- Страна оператора и тестировщиков — для доступности OpenAI/эквайринга.
- Telegram/OpenAI ключи уже добавлены владельцем в локальный `.env` и проверены; пополнение$10 подтверждено владельцем. Нужен первый пользовательский тест с фото и явным подтверждением.
- Согласованные фото взрослых для PoC и контакт поддержки.
- Перед продажами: реквизиты/чеки/оферта, договор и допустимая схема оплаты. ЮKassa выбрана для sandbox; внешняя оплата цифровых услуг внутри Telegram противоречит текущему требованию Stars. Внешний сайт сам по себе вопрос не решает.

Аудитория, функции и внешний сервис уже обсуждены; интервью не перезапускаем. Название «Образ», цены и метрики — гипотезы. Доказательства: `verification.md`; эксперимент: `POC.md`; источники Vibe: `vibe-payment-notes.md`.

Инструкция запуска/остановки и перехода на OpenAI: local-run.md. Двойной запуск запрещён; данные режимов разделены.

Дополнение 2026-10-08: по запросу владельца сравнены бесплатные платформы в [hosting-options.md](hosting-options.md). Oracle Always Free — кандидат для сохранения нынешнего Python-кода; Cloudflare — вариант после перехода на webhook/D1/Queue/R2; Telegram Serverless требует отдельного PoC условий. Целевая платформа ещё не выбрана, локальный запуск сохраняется. Нативные нижние и inline-кнопки используют явные цветовые стили Telegram.

Текущий путь размещения: Oracle показал общий отказ регистрации; [диагностика](oracle-signup-diagnosis.md) не установила исправляемую ошибку формы. Для Serverless созданы [план переноса](telegram-serverless-migration.md) и отдельный transport probe без OpenAI. Его offline smoke и статическое ревью пройдены; реальный cloud PoC, токен тестового приложения и контракты цены/секретов/runtime ещё нужны.

Если владелец выбирает показанные VPS, рекомендация — LC-2: 2vCPU/4GB/60GB, Ubuntu24.04LTS, публичный IPv4. LC-1: минимальный пилот; LC-3 пока не обоснован измерениями. В меню дополнительного ПО выбрать «Не выбрано»: WireGuard/OpenVPN не требуются боту. Python-зависимости и systemd ставятся при переносе. Это техническая рекомендация по предоставленным характеристикам, не подтверждение цены, доступности или качества провайдера и не заказ сервера.
