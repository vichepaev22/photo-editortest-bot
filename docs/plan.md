## Где работает бот

Сейчас bot/worker/API работают на Play2go VPS под systemd. Локальный экземпляр остановлен; компьютер владельца больше не нужен. История, фото и использованные trial-попытки перенесены со сверкой всех строк базы. GitHub Pages размещает интерфейс; API доступен через доверенный HTTPS на сервере. Детали и команды обслуживания — в [vps-deployment.md](vps-deployment.md).

Реализованный пилот: Telegram и Pages Mini App ↔ один процесс bot/worker/studio API на Linux VPS ↔ OpenAI API. На VPS находятся SQLite и временные фото. Long polling Telegram работает без webhook; Mini App использует Nginx HTTPS к loopback API. Платёжный модуль остаётся выключен до отдельного коммерческого запуска.

Технический ориентир VPS: 1–2 vCPU, 2 GB RAM, 20 GB диска, без GPU. Это оценка, не измеренная потребность. Провайдера, регион и тариф выбираем по доступности API и нагрузке; сервер не входит в $10 на API.

Перенос выполнен: один polling-процесс, автозапуск, согласованный backup ledger, проверка восстановления, квота и TTL фото. SQLite остаётся для малого однопроцессного пилота; масштабирование БД/очереди решается отдельно.
