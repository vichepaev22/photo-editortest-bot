## Где работает бот

Сейчас bot/worker/API работают на компьютере владельца. Фоновый процесс запущен в OpenAI-режиме; токен проверен на @photo_editortest_bot. При локальном тесте компьютер должен быть включён, подключён к сети и не уходить в сон. Локальная студия: http://127.0.0.1:8089/ . В live анонимное браузерное DEMO отключено. GitHub Pages размещает только HTML/CSS/JavaScript, Python на нём не исполняется; публичная Mini App остаётся предпросмотром до HTTPS API.

Предлагаемый пилот: Telegram и Pages Mini App ↔ один процесс bot/worker/studio API на Linux VPS ↔ OpenAI API. Там же SQLite и временные фото; отдельный billing-процесс принимает webhook через HTTPS. Long polling Telegram не требует собственного домена/входящего порта; Mini App API и платёжные webhook требуют доступного HTTPS-адреса. До настройки VPS Pages остаётся предпросмотром.

Технический ориентир VPS: 1–2 vCPU, 2 GB RAM, 20 GB диска, без GPU. Это оценка, не измеренная потребность. Провайдера, регион и тариф выбираем по доступности API и нагрузке; сервер не входит в $10 на API.

До переноса: секреты сервера, один polling-процесс, автозапуск, backup ledger, проверка восстановления, квота и TTL фото. SQLite — для малого однопроцессного пилота; масштабирование БД/очереди решается отдельно.
